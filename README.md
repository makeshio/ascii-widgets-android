# Ascii Widgets

Андроид-приложение с четырьмя домашними виджетами в стиле figlet/ASCII:

| Виджет | Размер | Что показывает |
| --- | --- | --- |
| Часы | 4×2 | время `HH:MM` и дату `dd.mm` |
| Погода | 2×2 | температуру и минимум/максимум дня |
| Батарея | 2×2 | заряд, статус зарядки, Wi-Fi и Bluetooth |
| Музыка | 4×1 | название текущего трека |

Прозрачный фон, монохромная палитра, только цифры, символы и короткие латинские аббревиатуры. Цифры рисуются прямоугольниками, а не текстом, поэтому вид не зависит от установленных шрифтов.

### Комбинирование стилей символов

В базе есть библиотека стилей (`styles` + `style_glyphs`) с тремя вариантами:

- **Классический** — плотные прямоугольные блоки;
- **Тонкий** — прямоугольники уменьшенного размера;
- **Точечный** — точки вместо квадратов.

В настройках можно независимо выбрать стиль для **цифр**, **символов** (`:`, `.`, `%`, `°`, `/`) и **букв**. По умолчанию комбинируются классические цифры, точечные символы и тонкие буквы — так разделители и единицы измерения не сливаются с цифрами. Выбор хранится в `settings.styleMap` и применяется ко всем четырём виджетам после нажатия «Сохранить и применить».

### Анимация

В `widget_frame.xml` используется `ViewFlipper` с двумя bitmap-кадрами и alpha-анимацией перехода (220 мс):

- часы — мигает двоеточие;
- погода — мигает знак градуса;
- батарея — пульсируют индикаторы зарядки, Wi‑Fi и Bluetooth;
- музыка — мигает первая буква названия трека.

Переключение кадров идёт раз в секунду через `AlarmManager`, но сами данные не перезапрашиваются: между минутными тиками используется кэш последней сетки. Анимацию можно выключить переключателем «Анимация индикаторов» в настройках — тогда секундные alarms не создают лишних обновлений.

## Технологии

- Kotlin + Jetpack Compose (Material 3)
- Room (SQLite) — библиотека ASCII-шаблонов и глифов
- AppWidget + `RemoteViews` с bitmap-рендером
- Данные: `java.time`, `BatteryManager`, Open-Meteo (без API-ключа), `MediaSessionManager`
- Gradle 8.13, AGP 8.13.2, Kotlin 2.3.21, KSP 2.3.14, Compose BOM 2025.06.00, Room 2.8.5

## База данных

`ascii_widgets.db` содержит таблицы:

- `templates` — шаблоны виджетов (имя, тип, размер сетки);
- `glyphs` — глифы 5×6 для каждого шаблона (`#` — закрашенная ячейка);
- `widget_configs` — соответствие `appWidgetId` → шаблон;
- `settings` — цвета, формат времени, город, автоопределение, рамка.

При первом запуске база заполняется четырьмя встроенными шаблонами. Глифы можно редактировать в приложении: **Библиотека ASCII-шаблонов → Править**, там же есть сброс к умолчанию.

## Сборка

Нужны JDK 17+ и Android SDK (platform 36, build-tools).

```powershell
.\gradlew.bat assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. После сборки он автоматически копируется в папку «Загрузки» под именем `ascii-widgets-debug.apk` (задача `copyDebugApkToDownloads`).

Юнит-тесты рендера:

```powershell
.\gradlew.bat testDebugUnitTest
```

## Установка и настройка

1. Установите `app-debug.apk` на телефон.
2. Добавьте виджет через долгий тап по рабочему столу → «Виджеты» → Ascii Widgets.
3. В конфигурации виджета выберите шаблон.
4. Откройте приложение и нажмите «Дать доступ к уведомлениям», чтобы виджет музыки видел текущий трек.
5. Для погоды укажите город или включите автоопределение и разрешите геолокацию.
6. Нажмите «Сохранить и применить».

Обновление виджетов планируется через `AlarmManager` раз в минуту; система также обновляет их после изменения настроек и перезагрузки устройства.

## Структура

```
app/src/main/java/com/makeshio/asciiwidgets/
├── data/      Room: сущности, DAO, база, начальные шаблоны и глифы
├── render/    символьная сетка и рендер в прозрачный bitmap
├── sources/   часы, батарея, погода, музыка
├── widget/    провайдеры, конфигурация, планировщик, listener уведомлений
└── ui/        Compose-экраны настроек и редактора глифов
```
