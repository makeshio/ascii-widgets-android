# Ascii Widgets

Андроид-приложение с ASCII/figlet-виджетами: монохром, прозрачный фон, только цифры, символы и короткие латинские аббревиатуры. Символы рисуются глифами из базы, а не системным текстом, поэтому вид не зависит от установленных шрифтов.

## Виджеты

| Виджет | Размер | Что показывает |
| --- | --- | --- |
| Часы | 4×2 | время `HH:MM` и дату `dd.mm` |
| Часы | 4×1 | только время, компактная сетка |
| Часы | 4×3 | время, дата и день недели |
| Погода | 2×2 | температуру и минимум/максимум дня |
| Погода | 4×2 | температуру и три ближайших часа (`19°20°21°`) |
| Батарея | 2×2 | заряд, статус зарядки, Wi‑Fi и Bluetooth |
| Музыка | 4×1 | название текущего трека |

Погода берётся из Open-Meteo без API-ключа; город задаётся вручную или определяется через геолокацию. Музыка читается через `NotificationListenerService` и `MediaSessionManager`.

## Возможности

- **Каталог** с живыми превью и тремя вкладками: «Виджеты», «Мои виджеты», «Настройки».
- **Добавление через системный API закрепления** (`requestPinAppWidget`) и запасная инструкция для OEM-лаунчеров, где добавление из приложения запрещено.
- **Индивидуальные настройки каждого виджета**: шаблон, пресет, два произвольных HEX-цвета, рамка, анимация, источник музыки. Пустые (`null`) значения наследуют глобальные настройки.
- **Пять ASCII-пресетов**: «Классика», «Точки», «Тонкий неон», «Минимум», «Контраст».
- **Комбинирование стилей**: независимо для цифр, символов и букв — классика, тонкий, точки.
- **Редактор глифов** в библиотеке шаблонов, поиск по шаблонам и сброс к умолчанию.
- **Точные будильники** (`SCHEDULE_EXACT_ALARM`) с запросом разрешения и fallback на неточные alarms.
- **Список «Мои виджеты»** с редактированием и сбросом настроек конкретного экземпляра.
- **Анимация индикаторов** через `ViewFlipper` с двумя bitmap-кадрами (220 мс): мигают `:` в часах, `°` в погоде, `C/W/B` в батарее и первая буква трека. Между минутными тиками данные берутся из кэша.

## Технологии

- Kotlin + Jetpack Compose (Material 3)
- Kotlin Coroutines, Room 2.8.5 (SQLite, версия схемы 4)
- AppWidget + `RemoteViews` с bitmap-рендером
- `java.time`, `BatteryManager`, `WifiManager`, `BluetoothAdapter`, Open-Meteo, `MediaSessionManager`
- Gradle 8.13, AGP 8.13.2, Kotlin 2.3.21, KSP 2.3.14, Compose BOM 2025.06.00

## База данных

`ascii_widgets.db` (версия 4) содержит таблицы:

- `templates` — 9 встроенных шаблонов (имя, тип, размер сетки);
- `glyphs` — глифы 5×6 для каждого шаблона (`#` — закрашенная ячейка);
- `styles` / `style_glyphs` — три стиля начертания;
- `presets` — пять готовых комбинаций стилей и цветов;
- `widget_configs` — настройки конкретного `appWidgetId` (шаблон, цвета, рамка, анимация, пресет, источник музыки);
- `settings` — глобальные значения по умолчанию.

Миграции `1→2`, `2→3`, `3→4` сохранены: обновление со старых версий не теряет пользовательские глифы. При первом запуске недостающие встроенные шаблоны досыпаются без перезаписи правок.

## Сборка

Нужны JDK 17+ и Android SDK (platform 36, build-tools).

```powershell
.\gradlew.bat clean assembleDebug testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. После сборки он автоматически копируется в папку «Загрузки» под именем `ascii-widgets-debug.apk` (задача `copyDebugApkToDownloads`).

## Установка и настройка

1. Установите `app-debug.apk` на телефон.
2. Откройте приложение → вкладка «Виджеты» → «Добавить на экран». Если лаунчер не поддерживает добавление из приложения, сделайте долгий тап по рабочему столу → «Виджеты» → Ascii Widgets.
3. В конфигураторе выберите шаблон, пресет, цвета и при необходимости пакет музыкального приложения → «Сохранить».
4. На вкладке «Настройки» нажмите «Дать доступ к уведомлениям» для виджета музыки и «Разрешить точные обновления».
5. Для погоды укажите город или включите автоопределение и разрешите геолокацию → «Сохранить и применить».
6. На вкладке «Мои виджеты» можно изменить или сбросить настройки уже добавленного виджета.

## Структура

```
app/src/main/java/com/makeshio/asciiwidgets/
├── data/      Room: сущности, DAO, база, миграции, шаблоны, пресеты
├── render/    символьная сетка и рендер в прозрачный bitmap
├── sources/   часы, батарея, погода, музыка
├── widget/    провайдеры, конфигуратор, планировщик, listener уведомлений
└── ui/        Compose: каталог, «Мои виджеты», настройки, превью, редактор глифов
```
